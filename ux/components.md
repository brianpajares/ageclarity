# Biblioteca de componentes
- `PrimaryButton`: solo uno principal por pantalla; focus-visible, disabled explicativo.
- `NumericLabField`: label, valor, selector de unidad, ayuda de informe y error claro; no autocorrección silenciosa.
- `StepProgress`: progreso de grupos y tiempo no estimado.
- `ResultComparison`: barras con edad cronológica y fenotípica, valores de texto; nunca semáforo diagnóstico.
- `ReportTeaser`: detalles explícitamente marcados como muestra; no fingir funcionalidades vendidas.
- `ConsentForm`: casilla opt-in sin premarcar para comunicaciones, envío separado de aceptación de privacidad.
- `Toast` accesible aria-live; `SourceLink` con identificación y fecha; `Card` resumen exportable.
- Interacción estados: idle, validando, calculado, error recuperable, resultado vacío. Diseño móvil-first 360 / tableta 768 / desktop 1280.
